FMSuperScout 24 - Football Manager 24 scouting tool
=============================================

INSTALL
-----------
1. Extract this whole folder (if you received a zip).
2. Double-click "Install FMSuperScout24.cmd".
3. You get a shortcut in the Start menu and on your desktop.

Node is bundled; you don't need to install anything else.

START
-------
Double-click the FMSuperScout 24 shortcut. The tool opens in its own window.
Close the window and the background server stops automatically.

DATA FROM FOOTBALL MANAGER
-------------------------
FMSuperScout 24 reads fm.exe directly with a read-only native memory reader.
Start FM24, load your save and click "New data" in the tool.

UNINSTALL
-----------
Via "Apps & features" (search for FMSuperScout 24), or run "Uninstall FMSuperScout24.cmd".
